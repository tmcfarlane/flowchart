# Flowchart v3.0.0

Published October 29, 2026.

Flowchart v3.0.0 is an official MIT-licensed, open-source release with three editing modes, native AI Draw generation, scoped AI edits, editable file exchange, and shared charts for people and MCP agents.

[Open Flowchart](https://flowchart.zeroclickdev.ai/) · [Source at v3.0.0](https://github.com/tmcfarlane/flowchart/tree/v3.0.0) · [Fork the project](https://github.com/tmcfarlane/flowchart/fork) · [Contribute](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/CONTRIBUTING.md) · [MIT license](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/LICENSE)

## Three editing modes

- Flowchart provides process steps, decisions, notes, images, and connected workflows.
- Architecture adds services, databases, queues, containers, protocol-aware connections, and bundled official Azure icons.
- Draw is our first-party SVG editor for freeform diagrams and annotations. It keeps shapes, text, paths, images, and frames editable without loading the Excalidraw editor or service.

Documents retain their selected mode, graph, and drawing data. See the [Draw guide](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-mode.md).

## AI proposals for the chosen canvas

- Generate a Flowchart, Architecture diagram, or native Draw scene. Preview, refine, or regenerate the proposal before insertion.
- AI Draw supports shapes, text, arrows, lines, pen paths, and frames. The backend measures text, fits shapes, resolves attachments, routes connectors, and validates the drawing before returning the finalized native file.
- Preview, presentation, and insertion consume the finalized drawing. Insertion remaps IDs and translates the scene without compiling it again.
- Generated text uses bundled Noto Sans with shared font measurements for the browser and SVG export. Invalid layouts fail before preview and leave the board unchanged.
- Native frames, text that wraps between words, visible arrowheads, protected labels, and stable bound connectors improve generated drawings.

See [AI Draw generation](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/ai-draw-generation.md) for generation limits and file behavior. Manual image upload, paste, and crop are supported. AI Draw generation does not create image assets.

## Review AI edits to a selection

- Select graph nodes in Flowchart or Architecture, request a change, and inspect the highlighted preview and change list. Apply commits one undoable change.
- Select existing unlocked Draw objects for scoped text and style changes. Draw geometry edits are limited to standalone, unassociated rectangles, diamonds, and ellipses.
- Selection requests keep their captured scope. Validation rejects stale or out-of-scope proposals before they change the document.

See [selected-node AI edits](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/selected-node-ai.md) and [selected Draw AI edits](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-selection-ai.md) for supported operations and relationship limits.

## Native drawing and editing tools

- Draw rectangles, diamonds, ellipses, arrows, lines, pen strokes, text, images, and frames. Use the eraser to remove objects.
- Change stroke and fill colors, thickness, dashes, hatching, sketch texture, corners, opacity, fonts, alignment, arrowheads, and routing.
- Resize, rotate, duplicate, copy, paste, group, lock, align, stack, or flip selections. Locked objects remain selectable for inspection and unlocking.
- Use box and lasso selection, connected-shape shortcuts, individual group-member selection, and keyboard connector-point editing. Shift constrains geometry, and Alt or Option draws shapes from their centers.
- Double-click shapes, existing text, and connectors to edit attached labels. Centered labels follow their shapes through movement, resizing, and rotation.
- Readable labels and visible paths adapt to dark and light surfaces without changing saved colors. Thin arrowheads remain visible at reduced zoom.
- Move frame contents together and clip them to the frame. Save reusable selections in the browser-local Components panel.
- Use drawing search, the command palette, statistics, element links, view mode, and zen mode. Pan with Hand, Space-drag, or a held right mouse button.
- Use the fading laser, eyedropper, fill, freehand shape recognition, and static HTTPS embed cards.
- Paste editable clipboard text, upload or paste images, and crop images from their original pixels.

The [Draw guide](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-mode.md), [keyboard reference](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/excalidraw-hotkeys.md), [media guide](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-media.md), and [extra tools guide](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-extra-tools.md) describe the controls.

## Editable import, export, and history

- Open or insert validated `.excalidraw` drawings as editable Draw objects. File-picker and canvas-drop imports share the same validation and destination confirmation.
- Import the supported Mermaid flowchart subset as editable shapes, labels, and connectors.
- Export the current Draw board as `.excalidraw`, and save complete editable documents as native JSON with an explicit mode.
- Export SVG, PNG, and GIF. Draw GIF export contains one still frame for the chosen duration.
- Use one Undo and Redo history across drawing edits, graph edits, imports, and mode changes. Standalone documents autosave locally.
- Present the complete Draw board with pan and zoom. Flowchart and Architecture retain their graph walkthroughs.

See [Excalidraw compatibility and limits](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/excalidraw-import.md) and the [supported Mermaid syntax](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/draw-extra-tools.md#mermaid-syntax). Imported fonts, sketch textures, and pinned elbow editing can differ from Excalidraw.

## Shared charts and MCP

- Create editable chart links and keep browser and agent changes in sync within a few seconds.
- Shared documents preserve drawings and the selected mode alongside graph data.
- Connect an MCP client to `https://flowchart.zeroclickdev.ai/api/mcp`. The hosted service needs no account or API key.
- Use `create_flowchart`, `get_flowchart`, `update_flowchart`, `list_node_types`, and `search_azure_icons`. MCP itself does not call an LLM.

The [MCP launch page](https://flowchart.zeroclickdev.ai/mcp) has client setup and the trailer. The [MCP reference](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/docs/mcp.md) covers tools, storage limits, link access, REST updates, and self-hosting.

## Open source and self-hosting

Use Node.js 20 or newer and npm. The canvas runs without AI credentials:

```sh
git clone https://github.com/tmcfarlane/flowchart.git
cd flowchart
git checkout v3.0.0
npm ci
npm run dev
```

Open `http://localhost:3004`. Production sharing and MCP require your own Redis configuration. Optional website AI uses your own server-side Azure settings and direct or authenticated gateway routing. Keep provider credentials out of browser variables. AI request limits, budgets, concurrency controls, and the disable switch remain in the shared server handler.

See [setup and configuration](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/README.md#run-locally-or-self-host), [AI operations](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/api/README.md#apichat), and [contributor instructions](https://github.com/tmcfarlane/flowchart/blob/v3.0.0/CONTRIBUTING.md).
