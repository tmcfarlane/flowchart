1. **Bound text selected alone jumps when flipped.** `flipSelection` treats a selected bound label as a target, then calls `rerouteBindings` with that label in `changed` (`src/utils/drawGeometry.ts:16-18,29-31,45`). `rerouteBindings` recenters every changed bound label on its container (`src/utils/drawScene.ts:200-220`). This discards its reflected position and can move it even when the container is locked. Minimal pure reproduction: create a locked 100x60 rectangle at `(0,0)` and an unlocked bound text element at `(10,10)` with `containerId` set to the rectangle ID; call `flipSelection(scene, ['text-id'], 'horizontal')`. The text moves to `(-40,16)` while the rectangle remains locked and unchanged. In the UI, Ctrl/Cmd-click the bound label for deep selection, then press Shift+H. An ordinary single-object horizontal flip around that label's own center should not translate it. The same failure occurs with an unlocked container. Add a controller and pure regression case for deep-selected bound text, including the locked host.

2. **The path tests do not catch corrupt width or height metadata.** The rotated freehand test checks world vertices and pressure samples, but `getWorldPoints` uses local points and ignores `width`/`height`; the browser verifier checks only negative local coordinates and pressure equality. The current implementation retains width and height, yet changing those fields to incorrect finite values inside `flipSelection` would leave these assertions green. Add assertions that a flipped authored path retains valid width/height and its rendered bounds, along with a selected bound connector case that checks both endpoint positions and fixed-point metadata after the flip. The current fixed-binding test checks one anchor value and the untouched opposite endpoint, but not the moved endpoint against its flipped shape.
