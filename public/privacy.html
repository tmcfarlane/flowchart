Flowchart AI privacy

Development policy draft, October 2, 2026. Operator and hosting retention details require approval before public plugin release.

Diagram tools receive only the chart information sent to them: titles, nodes, edges, icons and requested layout. They validate, arrange and store charts without calling an AI model. They do not request your full conversation. The browser's separate diagram assistant sends the requested prompt and supplied diagram context to the configured Azure OpenAI service. Installing the plugin does not change that service or billing. Using a user's ChatGPT AI allowance is a separate integration and is currently disabled.

Link sharing and storage

Anyone with a chart's view link can read it. Anyone with the private edit link can edit or permanently delete it. Charts have no account ownership. The server stores chart content and a hash of the edit capability. The browser stores the edit capability locally after removing it from the address bar. The MCP Apps card receives edit access through private UI metadata, which is excluded from model-visible tool results. Keep edit links private and do not paste them into chat.

Charts are retained indefinitely unless the operator enables Redis retention or an edit-link holder deletes them. A configured retention period applies after writes and does not automatically apply to untouched older records or development file stores. Loss of the edit link has no account-based recovery.

Browser preferences and recovery

The browser can automatically save a validated local diagram draft, store known template IDs marked as favorites, and keep metadata for the last requested Premium image. Local draft restoration requires review. The saved image request includes its description, style, size, request ID, state, timestamps and a non-authenticating account binding; it excludes credentials, generated image URLs and pixels. Favorites contain no diagram content and make no AI request. Clearing these local records removes local recovery and preferences; it does not delete server charts, cancel subscriptions or undo a provider request already started.

Optional Premium images and billing

Premium uses a separate private browser billing session. The server stores a hash of its capability and recovery code, Stripe customer/subscription references, paid status, usage counters and compact image-request claims. Stripe hosts payment and subscription-management pages; this website does not collect card fields. Requested image descriptions are sent to the configured OpenAI image provider. Generated images are stored as separate assets and can be deleted by their authenticated owner. Anyone with an image read URL, including through a shared chart, can read that image. Deleting an asset cannot erase existing downloaded or exported copies.

Completed image request results are recoverable for 24 hours. Compact same-request claims remain to prevent another provider attempt under the same ID. Browser billing-session expiry, image result expiry and chart retention are different mechanisms; operator backup and billing retention policies must be confirmed before release. Inference and payment providers apply their own processing and retention policies.

Delete a chart

Use Delete chart in the private card or Delete shared chart in the browser Share panel, then confirm. This removes the active stored record and invalidates its links. It cannot erase exports, screenshots, downloaded copies or diagram content already included in a conversation. Hosting-provider backup and log retention must be confirmed before release.

Other services

Hosting and storage providers process requests and service data. IP addresses are used for rate limiting; the browser may use hosting analytics. External images in diagrams can contact their image hosts and disclose the viewer's IP address. Use bundled icons when possible. ChatGPT and other clients apply their own privacy and conversation retention policies.

Do not save confidential data or credentials in link-shared charts. For general questions, see the project repository; do not post confidential charts or edit links in public issues.
